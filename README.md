# OverTheWire Writeups & Solvers

This repository contains my writeups for various OverTheWire wargames, along with additional context and explanations to better understand each challenge and its solution.

## Contents

* Step-by-step writeups for each level
* Extra notes and explanations for key concepts
* A simple solver script to quickly retrieve passwords for previous levels

## Solver Usage

A helper script is included to streamline progression for each game:

```bash
./solver.sh <level>
```

Example:

```bash
./solver.sh 5
```

This will output the password required to access level 5.

## Purpose

This repo serves as both a learning resource and a quick reference while working through OverTheWire challenges. It’s intended to reinforce practical Linux, networking, and security concepts.

## Disclaimer

These writeups are for educational purposes only. Try to solve each level yourself before using the solutions.
